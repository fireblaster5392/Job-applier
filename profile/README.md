# profile/

Your source of truth for every resume and cover letter. Nothing here is invented by the
pipeline; tailored resumes may only pick and lightly reword bullets from these files.

- `resume.yaml`: master resume (RenderCV format) with every bullet you've written, each with an id and tags.
- `answers.yaml`: contact info, links, work authorization, salary range, standard form answers.
- `stories/*.md`: STAR stories and project write-ups with real numbers.
